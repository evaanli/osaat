# font sources

## 3Dumb

- designer: Michael Tension / Tension Type
- bundled file: `3Dumb.ttf`
- typeface page: <https://www.dafont.com/3dumb-2dumb.font>
- license note: donationware; the designer requests a donation for commercial use

The font is bundled so the game's display headings render consistently without requiring a system font installation.
